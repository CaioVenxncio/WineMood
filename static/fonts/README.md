# Fonts

Self-hosted web fonts (Latin subsets, WOFF2), served by Streamlit's static file
serving and referenced from `.streamlit/config.toml`. All are licensed under the
SIL Open Font License 1.1; the licence texts are in the `LICENSE-*.txt` files.

| Font | Role | Source |
|---|---|---|
| Source Serif 4 (500, 600) | Headings | `@fontsource/source-serif-4@5.3.1` |
| Inter (400, 500, 600) | Body text | `@fontsource/inter@5.3.0` |
| JetBrains Mono (400, 500) | Metrics and numerals | `@fontsource/jetbrains-mono@5.3.0` |

If the files are missing, the theme falls back to system fonts.
